## 11. Résumé des Notations Grecques Courantes  

| Symbole  | Nom     | Rôle dans les LLMs                     |
| -------- | ------- | -------------------------------------- |
| \alpha   | alpha   | Taux d'apprentissage (*learning rate*) |
| \beta    | beta    | Paramètres de moment (Adam)            |
| \gamma   | gamma   | Facteur d'échelle (normalization)      |
| \delta   | delta   | Gradient (dérivée)                     |
| \epsilon | epsilon | Terme de stabilité (Adam, RMSprop)     |
| \zeta    | zeta    | Rarement utilisé                       |
| \eta     | eta     | Taux d'apprentissage (alternative)     |
| \theta   | theta   | Paramètres du modèle                   |
| \lambda  | lambda  | Régularization (L1, L2)                |
| \mu      | mu      | Moyenne, moment                        |
| \nu      | nu      | Vitesse (Adam)                         |
| \pi      | pi      | Distribution politique (RL)            |
| \rho     | rho     | Paramètre d'Adam                       |
| \sigma   | sigma   | Écart-type, fonction d'activation      |
| \tau     | tau     | Température (softmax)                  |
| \phi     | phi     | Fonction d'activation, paramètre       |
| \chi     | chi     | Rarement utilisé                       |
| \psi     | psi     | Rarement utilisé                       |
| \omega   | omega   | Poids, fréquence                       |
