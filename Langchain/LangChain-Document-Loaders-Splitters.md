# LangChain — Document Loaders et Text Splitters

**Dossier :** 06-RAG / LangChain  

## Document Loaders

Chargent des données depuis PDF, TXT, web, bases de données, etc.

## Text Splitters

Découpent les documents en chunks (RecursiveCharacterTextSplitter le plus courant).

Paramètres importants : chunk_size, chunk_overlap.

## Cas d’usage

Préparation des données pour le RAG métier.
