# LangChain — Introduction et Architecture

**Dossier :** 04-Agents / LangChain  
**Métiers :** AI Engineers, Product Engineers, AI Agent Ops

## Qu’est-ce que LangChain ?

LangChain est un framework open-source pour construire des applications avec des LLM. Il fournit des abstractions pour les prompts, les chains, les agents, la mémoire, les document loaders, les vector stores et les tools.

## Pourquoi l’utiliser ?

- Intégration facile avec de nombreux providers (OpenAI, Anthropic, Ollama…)
- Composants prêts à l’emploi pour RAG, agents, chatbots
- Architecture modulaire

## Composants principaux

- Models
- Prompts / Prompt Templates
- Chains
- Agents
- Memory
- Document Loaders & Text Splitters
- Vector Stores
- Tools
- Retrievers

## Cas d’usage métier

Base technique pour construire les agents que tu déploies en finance, immobilier, assurance, RH, BTP.
