# LangChain — Embeddings et Semantic Search

**Dossier :** 06-RAG / LangChain  

## Embeddings

Représentations vectorielles du texte. Modèles courants : OpenAI, Cohere, Hugging Face (sentence-transformers)…

## Métriques

- Cosine Similarity (la plus utilisée)
- Euclidean Distance
- Dot Product

## Workflow

Documents → Split → Embed → Vector Store → Retriever

## Cas d’usage

Base du retrieval dans tous les systèmes RAG.
