**Dossier :** 06-RAG

## Applications par domaine

| Domaine | Usage principal du RAG | Métriques clés |
|---------|------------------------|----------------|
| Finance / Banque | Conformité, reporting, analyse de risque | Faithfulness, Recall@k, Context Recall |
| Immobilier | Estimations, comparables, diagnostics | NDCG, MRR, Precision@k |
| Crypto | Analyse de protocoles, risques | Hybrid score, Faithfulness |
| Assurance | Sinistres, clauses | Cosine, Faithfulness |
| RH | Politiques multi-pays | Recall, Answer Relevancy |
| BTP | Facturation, normes | BM25 + cosine |
| Secteur public | Référentiels réglementaires | Guardrails + Faithfulness |

Le RAG est le socle de la plupart des agents métier que tu construis.
