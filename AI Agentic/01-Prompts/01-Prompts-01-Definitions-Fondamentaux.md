# 01-Prompts — 01-Definitions-Fondamentaux

**Dossier :** 01-Prompts  
**Métiers :** Product Engineers, AI Engineers, Forward-Deployed Engineers

## Définitions essentielles

- **System prompt** : instructions permanentes qui définissent le rôle, le périmètre, les contraintes et le format de sortie.
- **User prompt** : la demande concrète.
- **Few-shot** : exemples dans le prompt.
- **Chain-of-Thought** : raisonnement étape par étape.
- **Structured output** : sortie JSON / schéma forcé.
- **Prompt injection** : tentative de détourner le system prompt.

## Bonnes pratiques pour agents métier

Définir clairement le rôle, les outils autorisés, le format de réponse, les cas d’escalade et l’obligation de citer les sources.
