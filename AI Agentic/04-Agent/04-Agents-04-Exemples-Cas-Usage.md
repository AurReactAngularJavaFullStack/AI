# 04-Agents — 04-Exemples-Cas-Usage

**Dossier :** 04-Agents  
**Métiers :** AI Engineers, Product Engineers, Forward-Deployed Engineers

## Exemples d’agents

- **Finance** : agent d’analyse de dossier de crédit (outils de scoring + conformité).
- **Immobilier** : agent d’estimation de bien.
- **Crypto** : agent de monitoring de protocole.
- **Assurance** : agent de qualification de sinistre.
- **RH** : agent d’onboarding multi-pays.
- **BTP** : agent de génération de facture conforme.

Chaque agent laisse des traces et respecte les garde-fous.
