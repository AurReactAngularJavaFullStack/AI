# 11-Evaluation — 04-Exemples-Cas-Usage

**Dossier :** 11-Evaluation  
**Métiers :** AI Engineers, AI Agent Ops, Forward-Deployed Engineers

## Exemples d’évaluation

### Finance
Golden set de 50 questions de conformité. On mesure Faithfulness, Tool Call F1 et Agent Goal Accuracy avant chaque déploiement.

### Immobilier
Évaluation des estimations : l’objectif est atteint si la fourchette est correcte à ±10 %.

### Crypto
Détection correcte des risques majeurs dans un audit automatisé.

### Assurance / RH / BTP
Suites de tests de régression sur les flux critiques (sinistre, onboarding, facture).

Les métriques sont intégrées dans la CI/CD.
