# 02-Schemas — 04-Exemples-Cas-Usage

**Dossier :** 02-Schemas  

## Exemples de schémas

**Bancaire** : schéma strict pour une demande de crédit (montant, durée, garanties, revenus).

**Immobilier** : schéma pour une estimation (adresse, surface, type, DPE).

**Crypto** : schéma pour une simulation de transaction ou un audit de risque.

**Finance / Assurance / BTP** : schémas de conformité et de documents.
